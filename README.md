# OpenClaw Advanced Memory System

> 从线性笔记到分层大脑：用OpenClaw构建AI记忆系统

## 📖 项目简介

这个项目展示了如何基于OpenClaw构建一个高级Memory系统，解决AI助手的"金鱼记忆"问题。

### 核心特性

- **分层记忆架构**：L0-L3四层记忆，Token节省90%
- **对话树管理**：类似Git的分支、合并、切换
- **三级缓存**：L1(LRU) + L2(Redis) + L3(SQLite)
- **异步I/O**：批量写入(50条/批)，5秒刷新
- **后台任务**：5个自动任务，24小时运行
- **Obsidian同步**：每15分钟自动同步可视化

## 🚀 快速开始

### 安装依赖

```bash
cd openclaw-advanced-memory
npm install
```

### 启动系统

```bash
node start-advanced-memory-system.js
```

### 查看系统状态

访问Obsidian中的`_系统概览.md`，查看：
- 记忆总量（L0/L1/L2/L3）
- Token节省统计
- 后台任务状态
- 缓存命中率

## 📝 核心模块

### 1. 数据库层（SQLite）

- 对话树：支持分支、合并
- 索引优化：全文检索快10倍
- 事务支持：数据一致性有保障

### 2. 三级缓存

- L1缓存（内存）：LRU算法，微秒级访问
- L2缓存（Redis）：分布式缓存，毫秒级访问
- L3缓存（SQLite）：持久化存储，秒级访问

### 3. 异步I/O

- 批量写入（50条/批）
- 5秒定时刷新
- 失败自动重试（3次）

### 4. 后台任务调度

| 任务 | 频率 | 功能 |
|------|------|------|
| 记忆压缩 | 每天3点 | L0→L1→L2→L3 自动分层 |
| 衰减重算 | 每小时 | 根据访问频率调整记忆权重 |
| 向量索引 | 每5分钟 | 更新语义检索索引 |
| 缓存清理 | 每小时 | 清理过期缓存 |
| 统计收集 | 每天午夜 | 生成使用报告 |

### 5. 分支管理系统

类似Git的对话版本控制：

```javascript
// 创建新分支
memory.branch("alternative-approach")

// 合并分支
memory.merge("feature-branch")

// 切换分支
memory.checkout("version-2026-03-15")
```

### 6. Obsidian同步模块

每15分钟自动同步到Obsidian知识库：

```

├── 对话树/                # 可视化对话分支

```

## 💡 核心洞察

### 1. 记忆不是存储，是计算

**传统方案**：把对话存起来，需要时全文检索

**优化方案**：对话结束时就开始"计算记忆"
- 提取关键点（L1）
- 结构化知识（L2）
- 提炼洞察（L3）

### 2. Token优化是分层的

**误区**：直接截断历史对话

**正确做法**：
- L3层（核心洞察）：永远保留
- L2层（结构化知识）：优先保留
- L1层（关键点）：按需保留
- L0层（原始记录）：深度检索时才用

### 3. 记忆需要主动管理

**被动方案**：存进去就不动了

**主动方案**：
- 衰减重算：不用的记忆降权
- 记忆压缩：定期L0→L3
- 缓存清理：释放内存
